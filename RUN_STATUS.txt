HOW TO USE THE GUI:
================================================================================

Once models finish downloading, the GUI window will appear with:

1. INPUT BOX: Type your Hinglish text
   Example: "main theek hoon how are you"

2. ANALYZE BUTTON: Click to process the text

3. RESULTS DISPLAYED:
   📝 Input: Original text
   📄 Output: Converted text (Romanized Hindi → Devanagari)
   🔤 LIDs: Language identification for each word
   🌐 ML: English translation
   🗣️ MLI: Dominant language (Hindi/English)
   😊 Sentiment: Emotional tone (positive/negative/neutral)
   🏷️ NER: Named entities (people, places, organizations)
   📌 POS: Part-of-speech tags (color-coded)

COLOR CODING:
   🟣 Purple - Adjectives
   🔴 Red - Nouns
   🔵 Blue - Verbs
   🟡 Yellow - Adverbs
   🟢 Green - Named Entities
   🌸 Pink - Pronouns
   🟠 Orange - Prepositions
