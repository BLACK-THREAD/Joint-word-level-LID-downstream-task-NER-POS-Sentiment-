================================================================================
🐛 COMMON ISSUES & SOLUTIONS
================================================================================

ISSUE 1: "No module named 'tkinter'"
SOLUTION: 
  Windows: Reinstall Python, check "tcl/tk" option
  Mac: brew install python-tk
  Linux: sudo apt-get install python3-tk

ISSUE 2: "torch not found" or CUDA errors
SOLUTION: Install CPU version:
  pip install torch --index-url https://download.pytorch.org/whl/cpu

ISSUE 3: Models downloading very slowly
SOLUTION: 
  - Check internet connection
  - Try again later (HuggingFace servers may be busy)
  - Use a wired connection if possible

ISSUE 4: "lid.176.bin not found"
SOLUTION: 
  - Verify file is in the same folder as .py files
  - Re-extract the zip file
  - Download manually if needed

ISSUE 5: Out of memory
SOLUTION:
  - Close other applications
  - Ensure at least 4 GB RAM available
  - Restart computer and try again
