================================================================================
                    HINGLISH TEXT ANALYZER - SETUP GUIDE
================================================================================

📦 QUICK START (3 Steps)
================================================================================

1. INSTALL PYTHON DEPENDENCIES
   
   Open terminal/command prompt in the project folder and run:
   
   pip install -r requirements.txt
   
   OR (if pip3 is required):
   
   pip3 install -r requirements.txt


2. VERIFY FASTTEXT MODEL
   
   Check if 'lid.176.bin' file exists in the project folder.
   Size should be approximately 126 MB.
   
   If missing, download it:
   
   curl -o lid.176.bin https://dl.fbaipublicfiles.com/fasttext/supervised-models/lid.176.bin


3. RUN THE APPLICATION
   
   python hinglish_analyzer_gui.py
   
   OR:
   
   python3 hinglish_analyzer_gui.py


================================================================================
🖥️  PLATFORM-SPECIFIC INSTRUCTIONS
================================================================================

WINDOWS
-------
1. Install Python 3.8+ from python.org
2. Open Command Prompt (cmd) in project folder
3. Run: pip install -r requirements.txt
4. Run: python hinglish_analyzer_gui.py

Note: If tkinter is missing, reinstall Python with "tcl/tk" option checked


macOS
-----
1. Python 3 is usually pre-installed
2. Open Terminal in project folder
3. Run: pip3 install -r requirements.txt
4. Run: python3 hinglish_analyzer_gui.py

Note: If tkinter issues occur, run: brew install python-tk


LINUX (Ubuntu/Debian)
---------------------
1. Install Python: sudo apt-get install python3 python3-pip python3-tk
2. Open Terminal in project folder
3. Run: pip3 install -r requirements.txt
4. Run: python3 hinglish_analyzer_gui.py


================================================================================
⚠️  TROUBLESHOOTING
================================================================================

PROBLEM: "No module named 'tkinter'"
SOLUTION: 
  - Windows: Reinstall Python with tcl/tk option
  - macOS: brew install python-tk
  - Linux: sudo apt-get install python3-tk


PROBLEM: "torch not found" or CUDA errors
SOLUTION: Install CPU version of PyTorch:
  pip install torch --index-url https://download.pytorch.org/whl/cpu


PROBLEM: Models downloading slowly
SOLUTION: First run downloads ~2GB of models. Be patient. Subsequent runs are fast.


PROBLEM: Out of memory
SOLUTION: Close other applications. The models need ~2GB RAM.


PROBLEM: "lid.176.bin not found"
SOLUTION: Download manually:
  https://dl.fbaipublicfiles.com/fasttext/supervised-models/lid.176.bin
  Place in project root folder.
