📋 CORE APPLICATION FILES
================================================================================

1. hinglish_analyzer_gui.py
   -------------------------
   PURPOSE: Main graphical user interface application
   
   FEATURES:
   - Dark-themed Tkinter GUI
   - Text input box for Hinglish text
   - Real-time analysis with threading
   - Color-coded output for POS tags and entities
   - Displays: LID, ML, MLI, Sentiment, NER, POS
   
   HOW TO RUN:
   python hinglish_analyzer_gui.py
   
   DEPENDENCIES:
   - tkinter (GUI framework)
   - fasttext (language detection)
   - transformers (NLP models)
   - All dictionaries and helper functions
   
   OUTPUT:
   Interactive GUI window with analysis results


2. complete_hinglish_pipeline.py
   ------------------------------
   PURPOSE: Complete NLP analysis pipeline (command-line)
   
   FEATURES:
   - Processes Hinglish text through all stages
   - Converts Romanized Hindi to Devanagari
   - Detects language per word (LID)
   - Translates to English (ML)
   - Identifies dominant language (MLI)
   - Performs Sentiment, NER, POS analysis
   
   HOW TO RUN:
   python complete_hinglish_pipeline.py
   
   OUTPUT:
   Console output with formatted analysis results
   Example test cases included in the file


3. correct_hinglish_converter.py
   ------------------------------
   PURPOSE: Hinglish to Devanagari converter with LID
   
   FEATURES:
   - Converts Romanized Hindi words to Devanagari
   - Keeps English words unchanged
   - Word-level language detection
   - English translation (Matrix Language)
   - Matrix Language Index calculation
   
   HOW TO RUN:
   python correct_hinglish_converter.py
   
   ALGORITHM:
   1. Split text into words
   2. Detect language for each word (FastText + dictionary)
   3. Convert Hindi words to Devanagari
   4. Keep English words as-is
   5. Generate English translation
   6. Calculate dominant language
   
   OUTPUT:
   - Converted text (mixed script)
   - Language IDs per word
   - English translation
   - Matrix Language Index

4. evaluate_model_final.py
   -----------------------
   PURPOSE: Model evaluation on COMI-LINGUA dataset
   
   FEATURES:
   - Tests LID accuracy on test dataset
   - Calculates metrics (accuracy, precision, recall, F1)
   - Generates visualization charts
   - Creates detailed evaluation report
   
   HOW TO RUN:
   python evaluate_model_final.py
   
   REQUIREMENTS:
   - COMI-LINGUA/LID_test.csv must exist
   
   OUTPUT:
   - report/evaluation_report.txt
   - report/visualizations/accuracy.jpg
   - report/visualizations/distribution.jpg
   - report/visualizations/performance.jpg
   
   METRICS:
   - Accuracy: 68.79%
   - Test samples: 100 sentences (2,009 words)

11. lid.176.bin
    -----------
    TYPE: Binary model file
    SIZE: ~126 MB
    
    PURPOSE: FastText language identification model

    - Hindi (hi)
    - And 174 others

13. COMI-LINGUA/
    ------------
    PURPOSE: Code-Mixed Linguistic Annotation dataset
    
    SOURCE: LINGO Lab, IIT Gandhinagar
    
    FILES:
    - LID_test.csv (22 MB) - Language ID test data
    - LID_train.csv (84 MB) - Language ID training data
    - MLI_test.csv (1.1 MB) - Matrix Language Index test
    - MLI_train.csv (4.3 MB) - Matrix Language Index training
    - NER_test.csv (19 MB) - Named Entity Recognition test
    - NER_train.csv (86 MB) - Named Entity Recognition training
    - POS_test.csv (18 MB) - Part-of-Speech test
    - POS_train.csv (70 MB) - Part-of-Speech training
    - MT_test.csv (11 MB) - Machine Translation test
    - MT_train.csv (47 MB) - Machine Translation training
    
    FORMAT: CSV with JSON-encoded annotations
    
    USAGE: Used by evaluation scripts
